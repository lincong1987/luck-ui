颜色决定设计系统的视觉基调。Luck UI 的调色板以暖灰与橙色为核心，并在 OKLCH 色彩空间中扩展为完整色阶，以保证浅色与暗色模式下的亮度一致性与可访问性。

灰色带有细微的暖色倾向——比中性灰更暖，又不像 Tailwind 的 Stone 那样明显——为整体奠定平衡的基础。橙色作为主强调色，为调色板注入活力与温度；红色与绿色则分别承担危险与成功的反馈。

像 `text-gray-500`、`bg-gray-100`、`border-gray-200`、`text-green-600` 以及 `dark:` 变体这样的常用 Tailwind 工具类，都会映射到 Luck UI 底层的主题令牌。

## 交互状态

每个表面令牌都为可交互元素配备了 `-hover` 与 `-active` 伴随令牌。这里没有用透明度淡化基础色——那样会与背后的内容不可预测地叠加，让多层表面变得浑浊——而是借助 `color-mix` 从基础令牌推导出固定、不透明的状态色。每个不透明表面都向 `--foreground` 混合，因此同一套公式在浅色模式下会加深颜色，在暗色模式下会自动提亮（像 `primary` 这样的实心填充则改为向自身的前景色混合）。最终得到的是真实、不透明的变化，无论背景如何都清晰可辨。

直接把它们当作 Tailwind 工具类使用——例如 `hover:bg-primary-hover`、`data-popup-open:bg-secondary-active` 等——这样明暗逻辑就留在主题里，无需在每个组件中重复声明。
