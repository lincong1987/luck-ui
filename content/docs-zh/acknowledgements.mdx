**Luck UI** 的诞生离不开开源社区了不起的工作。感谢以下项目带来的灵感、底层原语与设计范式。

## [Base UI](https://base-ui.com)

Luck UI 中每个组件的基石。Base UI 提供无样式、可访问的 React 原语，具备可靠的键盘导航与焦点管理。

## [shadcn/ui](https://ui.shadcn.com)

开创了 Luck UI 所沿用的复制粘贴式组件模式。其注册表架构、CLI 工具与文档范式都带来了深远影响。

## [Coss UI](https://coss.com/ui)

启发了组件设计决策与样式范式。
