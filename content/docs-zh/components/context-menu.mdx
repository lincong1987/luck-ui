## 示例

### 带附属内容

用 `ContextMenuItemAddon` 添加图标、文本或其他补充内容。放在 `ContextMenuItemLabel` 之前为前置附属内容，放在标签之后为后置附属内容。

### 复选框项

使用 `ContextMenuCheckboxItem` 表示可切换的选项。

> **注意：** 复选框指示器会占用前置附属内容列。请避免再添加前置的 `ContextMenuItemAddon`；如需补充内容，请放在 `ContextMenuItemLabel` 之后。
